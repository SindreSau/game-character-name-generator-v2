# Game Name Generator - Copilot Guide

## Project Overview

Next.js 15 app that generates game character names using AI based on user parameters (genre, style, complexity).

## Key Patterns

### Structure

- `src/components/ui/`: shadcn/ui components
- `src/components/general/`: app-wide components
- `src/components/form-generator/`: name generator components
- `src/app/`: Next.js pages
- `src/actions/`: Server Actions for AI API calls
- `src/hooks/`: React hooks
- `src/types/`: TypeScript types

### Naming & Style

- Files: kebab-case (`custom-slider.tsx`)
- Components: PascalCase (`FormResults`)
- Functions: camelCase (`generateCharacterNames`)
- Server Actions: suffix with `.server.ts`
- Use Tailwind CSS with shadcn/ui components
- Use `<FadeInSection>` for animations

### Components

- Client components: Add `'use client'` at top
- Use react-hook-form with zod for forms
- Use sonner toast for notifications
- Follow types in `src/types/name-generator.ts`

### API & Data Flow

- Server Actions handle AI API calls
- Structure responses as: `{ success: boolean, message: string, names: string[] }`
- Implement fallback between Cloudflare and Gemini APIs

## Example Patterns

**Client Component:**

```tsx
'use client';

import { useState } from 'react';
import { Button } from '@/components/ui/button';
import { FadeInSection } from '@/components/general/fade-in-section';
import { toast } from 'sonner';

export default function MyComponent() {
  const [isLoading, setIsLoading] = useState(false);

  const handleAction = async () => {
    setIsLoading(true);
    try {
      // Action logic
      toast.success('Success message');
    } catch (error) {
      toast.error('Error message');
    } finally {
      setIsLoading(false);
    }
  };

  return (
    <FadeInSection delay={100}>
      <div className="container mx-auto p-4">
        <Button onClick={handleAction} disabled={isLoading}>
          {isLoading ? 'Loading...' : 'Action'}
        </Button>
      </div>
    </FadeInSection>
  );
}
```

**Server Action:**

```ts
'use server';

import { CharacterNameInput } from '@/types/name-generator';

export async function myServerAction(input: CharacterNameInput) {
  try {
    // Implementation
    return {
      success: true,
      message: 'Success message',
      names: ['Name1', 'Name2'],
    };
  } catch (error) {
    console.error('Error:', error);
    return {
      success: false,
      message: `Error: ${
        error instanceof Error ? error.message : 'Unknown error'
      }`,
      names: [],
    };
  }
}
```
